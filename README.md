Landing page de portfólio construída em HTML, CSS e JavaScript puro, com Bootstrap para estrutura de layout e responsividade. O site reúne:

Apresentação inicial com efeito de "máquina de escrever"
Seção de skills (Front-End, Back-End e Ferramentas)
Galeria de sites desenvolvidos, com links externos
Portfólio digital com peças em PDF exibidas em modal
Seção "Sobre" com links para LinkedIn e GitHub
Botão flutuante "voltar ao topo"
Currículo disponível para download direto na página
Tecnologias utilizadas
HTML5
CSS3
JavaScript (vanilla)
Bootstrap 5.3
Bootstrap Icons
Google Fonts (Libre Baskerville e Poppins)
